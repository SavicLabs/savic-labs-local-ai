# Configure Your Endpoint

SavicLabs connects to your local llama.cpp or any OpenAI-compatible API endpoint.

**Default**: `http://127.0.0.1:18080/v1`

**To configure:**
1. Open the Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`)
2. Run **SavicLabs: Configure Endpoint**
3. Enter the URL of your API server

**Tip**: Make sure your llama.cpp router is running before selecting a model.
