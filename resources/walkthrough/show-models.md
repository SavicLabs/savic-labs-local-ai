# Select a Model

Your local models now appear in the Copilot Chat model picker.

1. Open Copilot Chat (`Ctrl+Shift+I` / `Cmd+Shift+I`)
2. Click the model dropdown in the chat input
3. Find **SavicLabs** section with your discovered models
4. Select a model and start chatting!

**Model capabilities are auto-detected:**
- 🧠 **Qwen models** — thinking/reasoning blocks
- 🔧 **All models** — tool calling support
- 🖼️ **Vision proxy** — images auto-described via Copilot vision models
